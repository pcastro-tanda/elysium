# Lint/BooleanSymbol

Checks for `:true` and `:false` symbols.

| | |
| --- | --- |
| Department | Lint |
| Enabled by default | true |
| Default severity | warning |
| Fix | unsafe |
| Stability | stable |

In most cases it would be a typo.

## Options

This rule has no options.

## Blind spots

None recorded.
