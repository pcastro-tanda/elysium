# Style/Encoding

Checks ensures source files have no utf-8 encoding comments.

| | |
| --- | --- |
| Department | Style |
| Enabled by default | true |
| Default severity | convention |
| Fix | safe |
| Stability | stable |

Checks ensures source files have no utf-8 encoding comments.

```ruby
# bad
# encoding: UTF-8
# coding: UTF-8
# -*- coding: UTF-8 -*-
```

## Options

This rule has no options.

## Blind spots

None recorded.
