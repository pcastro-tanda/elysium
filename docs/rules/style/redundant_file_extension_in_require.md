# Style/RedundantFileExtensionInRequire

Checks for the presence of superfluous `.rb` extension in the filename provided to `require` and `require_relative`.

| | |
| --- | --- |
| Department | Style |
| Enabled by default | true |
| Default severity | convention |
| Fix | safe |
| Stability | stable |
