# Style/TrailingMethodEndStatement

Checks for trailing code after the method definition.

| | |
| --- | --- |
| Department | Style |
| Enabled by default | true |
| Default severity | convention |
| Fix | safe |
| Stability | stable |

Method bodies whose final statement shares a line with the closing `end` are hard to read; the `end` should be on its own line.

## Options

This rule has no options.

## Blind spots

None recorded.
