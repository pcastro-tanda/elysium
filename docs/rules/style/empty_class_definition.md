# Style/EmptyClassDefinition

Enforces consistent style for empty class definitions.

| | |
| --- | --- |
| Department | Style |
| Enabled by default | false |
| Default severity | convention |
| Fix | safe |
| Stability | stable |



## Options

| Name | Default | Allowed values | Description |
| --- | --- | --- | --- |
| EnforcedStyle | `class_keyword` | `class_keyword`, `class_new`, `class_definition` | Whether to prefer a standard class definition or `Class.new`. |
| AllowedParentClasses | `[]` |  | Parent classes for which both styles are permitted. |

## Blind spots

None recorded.
