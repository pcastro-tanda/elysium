# Style/RedundantArrayConstructor

Checks for the instantiation of array using redundant `Array` constructor.

| | |
| --- | --- |
| Department | Style |
| Enabled by default | false |
| Default severity | convention |
| Fix | safe |
| Stability | stable |

Checks for the instantiation of an array using a redundant `Array` constructor. Autocorrect replaces it with an array literal which is the simplest and fastest.

## Options

This rule has no options.

## Blind spots

None recorded.
