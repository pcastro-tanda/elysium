# Style/UnlessElse

Do not use unless with else. Rewrite these with the positive case first.

| | |
| --- | --- |
| Department | Style |
| Enabled by default | true |
| Default severity | convention |
| Fix | safe |
| Stability | stable |

Looks for `unless` expressions with `else` clauses.

## Options

This rule has no options.

None recorded.
