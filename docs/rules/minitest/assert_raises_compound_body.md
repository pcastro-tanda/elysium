# Minitest/AssertRaisesCompoundBody

This cop enforces the block body of `assert_raises { ... }` to be reduced to only the raising code.

| | |
| --- | --- |
| Department | Minitest |
| Enabled by default | false |
| Default severity | convention |
| Fix | none |
| Stability | stable |



## Options

This rule has no options.

## Blind spots

None recorded.
