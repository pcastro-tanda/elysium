# Sorbet/ForbidRBIOutsideOfAllowedPaths

Forbids RBI files outside of the allowed paths

| | |
| --- | --- |
| Department | Sorbet |
| Enabled by default | true |
| Default severity | convention |
| Fix | none |
| Stability | stable |



## Options

| Name | Default | Allowed values | Description |
| --- | --- | --- | --- |
| AllowedPaths | `rbi/**`, `sorbet/rbi/**` |  | A list of the paths where RBI files are allowed. |

## Blind spots

None recorded.
