# Rails/AssertNot

Use `assert_not` instead of `assert !`.

| | |
| --- | --- |
| Department | Rails |
| Enabled by default | true |
| Default severity | convention |
| Fix | safe |
| Stability | stable |

Use `assert_not` instead of `assert !`.

```ruby
# bad
assert !x

# good
assert_not x
```

## Options

This rule has no options.

None recorded.
