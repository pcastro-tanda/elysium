# Layout/SpaceAfterNot

Tracks redundant space after the ! operator.

| | |
| --- | --- |
| Department | Layout |
| Enabled by default | true |
| Default severity | convention |
| Fix | safe |
| Stability | stable |

Checks for space after `!`.

```ruby
# bad
! something

# good
!something
```

## Options

This rule has no options.

## Blind spots

None recorded.
