# Layout/EmptyLinesAroundBeginBody

Keeps track of empty lines around begin-end bodies.

| | |
| --- | --- |
| Department | Layout |
| Enabled by default | true |
| Default severity | convention |
| Fix | safe |
| Stability | stable |

```ruby
# bad
begin

  # ...

end

# good
begin
  # ...
end
```

## Options

This rule has no options.

## Blind spots

None recorded.
