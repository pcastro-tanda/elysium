# Layout/EmptyLinesAroundMethodBody

Keeps track of empty lines around method bodies.

| | |
| --- | --- |
| Department | Layout |
| Enabled by default | true |
| Default severity | convention |
| Fix | safe |
| Stability | stable |

```ruby
# good

def foo
  # ...
end

# bad

def bar

  # ...

end
```

## Options

This rule has no options.

## Blind spots

None recorded.
