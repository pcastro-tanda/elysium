# Layout/SpaceBeforeComment

Checks for missing space between a token and a comment on the same line.

| | |
| --- | --- |
| Department | Layout |
| Enabled by default | true |
| Default severity | convention |
| Fix | safe |
| Stability | stable |

```ruby
# bad
1 + 1# this operation does ...

# good
1 + 1 # this operation does ...
```

## Options

This rule has no options.

## Blind spots

None recorded.
